# HIDA v2.1 — 5層意識モデル（Fable 5 レビュー版）

> 意識なんて分からん。じゃあ実装してみよう。

このフォルダは HIDA（5層意識モデル）の **v2.1 リリース一式**です。理論・実装・検証・変更履歴がここで揃っています。

HIDA は「意識とは何か」を定義から論じるのではなく、**動く実装を先に置いて逆算する**プロジェクトです。グリッドワールドを動く一体のエージェントとして、身体・クオリア・予測・記憶・意識の5層を実装し、その挙動を観察します。現象的意識（クオリアの「感じ」そのもの）を解明したという主張では **ありません**。特定の機能的アーキテクチャを実際に走らせたら何が起きるかを見る道具です。

## 設計思想

**1. 実装は証明。** 言葉で述べたことは、走らせて確かめるまで主張にしない。検証していないものには「未検証」の札を貼る（下の検証状況を参照）。

**2. 主体を作らない。** どの層にも「見ている誰か（ホムンクルス）」を置かない。意識の座は動き、注意も覚醒も動くが、中央に司令塔となる主体は据えない。各層は反応の重み付けとその同期であって、それを俯瞰する中心点は存在しない。

**3. とにかくやってみる。** 完璧な理論を待たず、実装し、壊れたところを直しながら進める。

理論の起点は2025年11月、「思考とは記憶の重ね合わせである」という着想。AI は「参照ツール、判断は人間」で一貫して運用している。

## 5層アーキテクチャ

| 層 | 役割 |
|----|------|
| **L1 身体層** (`L1Body`) | 位置・方向・エネルギー・疲労、感覚入力 |
| **L2 クオリア層** (`L2Qualia`) | valence/arousal の2軸（Russell円環）＋個別感情、原因の記録と減衰 |
| **L3 予測層** (`L3Prediction`) | L4記憶から予測を立て、感覚と突き合わせて予測誤差を出す |
| **L4 記憶層** (`L4Memory`) | 内部マップ、発見物、活性化カウンタ、長期記憶（`hida_ltm.json`）、経験からの変調値（`hida_modulation.json`） |
| **L5 意識層** (`L5Consciousness`) | 各層の活動から主導層を検出し同期スコアを算出。意識ON/OFFをヒステリシス判定。LLMによる内省の言語化 |

意識の有無は「対称的な相互同期」ではなく、**主導層（leader）が追随層（follower）を引き込む非対称な同期**としてモデル化される。どの層が主導するかは状況で変わる。

## v2.1 で何が変わったか

v2.1 は**理論には一切手を触れず**、v2.0 実装が理論の主張を支えきれていなかった3点を、実装側から追いつかせた改訂です。詳細と数値は `CHANGELOG_v2_1.md` を参照。

**修正1 — 同期スコアの約分問題。** v2.0 では主導強度が定義上つねに最大活動量のため、スコア式で約分されて消え、実質「追随層の活動量平均」になっていた。v2.1 は幾何平均 `raw_sync = sqrt(leader_strength × coherence)` に変更し、主導強度と追随整合性が独立にスコアへ寄与するようにした。スコア値域が変わるため ON/OFF 閾値を 0.03/0.02 → **0.08/0.05** に再較正（同一シナリオ・同一シードで意識ON頻度を維持することを基準に確認）。

**修正2 — 非対称性を測定から力学へ。** v2.0 の非対称性は `sync_type` というラベル上にしか無く、主導層が追随層を実際に引き込む機構が無かった。v2.1 は主導強度に応じて追随層の更新ゲインを `1 + ENTRAIN_K × leader_strength`（`ENTRAIN_K = 0.5`）に引き上げる。L1=身体動員、L2=情動応答感度、L3=誤差検出感度、L4=記憶活性化感度として作用し、「主導→追随」の時間的因果が初めて力学として実在する。

**修正3 — 追随整合性への時間遅れ成分。** 同時相関だけでなく、前ステップの主導信号への遅れた応答を `LAG_WEIGHT = 0.5` で合成する。「たまたま同時に活発」と「引き込まれた」を時間遅れ成分が区別する。修正2があるため、この成分に測定すべき実体がある。

閾値・係数（`LEADER_THRESHOLD`, `ON/OFF_THRESHOLD`, `EMA_ALPHA`, `ENTRAIN_K`, `LAG_WEIGHT`）は「このコードの生まれながらの値（DNA初期値）」として扱い、最適値の探索は今後の課題。

## 実行方法

Python 3 のみで動作（L5の言語化を使う場合のみ LLM アクセスが必要）。

```bash
# 通常モード（2テスト）
python3 hida_unified_v2.py

# 低エネルギー5回連続（慎重な性格が形成される）
python3 hida_unified_v2.py loop

# 高エネルギー5回連続（冒険的になる）
python3 hida_unified_v2.py loop_high

# 記憶・変調値をリセット
python3 hida_unified_v2.py reset

# 引き込み機構のアブレーション検証
python3 test_entrainment_ablation.py
```

エージェントはグリッドワールドで色付きボールを拾いゴールを目指す。危険ゾーン・腐ったボール・妨害NPCが配置され、色の好み（DNA）と経験からの変調値で行動と内省が変化する。実行を繰り返すと経験が蓄積し、性格が育つ。

## 検証状況

**検証済み（アブレーションが裏を取った）**

`test_entrainment_ablation.py`、同一シナリオ・30シードで `ENTRAIN_K = 0`（OFF）と `0.5`（ON）を比較：

| 指標 | OFF | ON |
|------|-----|-----|
| 主導イベント直後の追随層活動上昇（平均） | 0.0154 | 0.0174 |
| 時間遅れ相関 r(主導強度 t, 追随平均 t+1) | −0.110 | −0.031 |
| シード単位の勝率（ON > OFF） | — | 25/30（偶然なら p ≈ 0.0003） |

**正直な注記：** 効果量は小さい。検証環境が静的なグリッドワールドで、追随層が応答できるイベント（予測誤差・情動増分）自体が疎なため。効果を大きく見せるために `ENTRAIN_K` を盛ることはしていない。主張できるのは「引き込みONで因果方向の相関が一貫して改善する」ことまで（時間遅れ相関は両条件とも負であり、これはスパイク後に活動が減衰する系では自然）。方向が一貫して正しいことがここでの主張のすべて。

**未検証（札を貼ってあるもの）**

- 「意識の座は動く」（論文 §5）は該当シナリオを走らせておらず予測にとどまる
- 各DNA定数の最適値は未探索
- 時間遅れ応答は1ステップ遅れのみ。複数ステップ伝播（位相同期・伝達エントロピー）は将来課題
